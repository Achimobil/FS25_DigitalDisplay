# FS25_DigitalDisplay

![Status](https://img.shields.io/badge/status-released-4CAF50)
![Platform](https://img.shields.io/badge/Farming%20Simulator-25-4CAF50)
![License](https://img.shields.io/badge/license-custom-lightgrey)

**Digitalanzeigen** zeigen den Inhalt der nächstgelegenen Produktion, eines Mithaufens, eines
Tierstalls (sofern dieser ein Lager wie z. B. Wasser oder Gülle besitzt) oder eines Silos (kein
Objektlager) an – alle Inhalte alphabetisch sortiert, mit automatischem Paging bei vielen
Einträgen.

Enthalten sind ein klobiges Stand-Display sowie mehrere Wanddisplays mit 3 bis 26 Zeilen, dazu ein
26-zeiliges Wanddisplay mit doppelter Breite für 52 anzeigbare Inhalte. Für Wanddisplays ohne
geeignete Anbaufläche liegt außerdem ein Mast bei.
